# Student–Teacher Appointment Booking System

A full-stack web application that makes it easier for students to book appointments with teachers. Students can check available slots, request appointments, and keep track of their bookings, while teachers can manage their availability and appointment requests.

## What it can do

- Students can sign up, log in, and book appointments with teachers
- Students can view their upcoming and previous appointments
- Teachers can create and manage available appointment slots
- Teachers can approve or reject appointment requests
- Different dashboards and access are provided for students, teachers, and admins
- Email notifications are sent for appointment updates
- JWT is used for user authentication

## Tech Stack

- React
- Tailwind CSS
- Node.js
- Express
- MongoDB
- JWT

## Project Structure

frontend/ → React frontend  
backend/ → Node.js and Express backend

## Running the Project

Backend:

    cd backend
    npm install
    npm start

Frontend:

    cd frontend
    npm install
    npm run dev

The backend requires the environment variables mentioned in `.env.example`.
